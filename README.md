# Лендинги для кафе и ресторанов — портфолио

Ветка `food-landings`. Она отделена от лендингов автосервисов (у неё нет общей истории с `main`).

15 демо-лендингов заведений общепита в разных стилях. Каждый — один HTML-файл без сборки и без зависимостей
(кроме шрифтов Google Fonts): откройте в браузере или выложите на любой хостинг.

Корневой `index.html` — витрина со ссылками на все сайты и фильтром «светлые / тёмные / яркие».

## Что общего у всех сайтов

- Адаптивная вёрстка от 320 px до широких экранов, бургер-меню на телефоне.
- Плавное появление блоков при прокрутке и небольшие декоративные анимации.
- Анимации отключаются при системной настройке «уменьшить движение».
- Формы брони и заказа показывают сообщение об успехе, но никуда не отправляют данные: для реального сайта
  их нужно подключить к почте, Telegram-боту или CRM.
- Вместо фотографий стоят эмодзи и CSS-иллюстрации. Для заказчика их стоит заменить на настоящие фото блюд и зала.
- Названия, адреса, телефоны, цены и отзывы — заглушки.

## Публикация

У репозитория один сайт GitHub Pages, и сейчас он собирается из `main` (лендинги СТО). Поэтому эта ветка
автоматически **не** публикуется, чтобы не затереть сайты автосервисов. Варианты:

- открыть любой `food-XX/index.html` локально в браузере — сайты работают без сервера;
- залить папки на Netlify / Vercel / любой хостинг (перетащить папку в Netlify Drop);
- вынести ветку в отдельный репозиторий со своим GitHub Pages.
