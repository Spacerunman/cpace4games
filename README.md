# cpace4games

## sto-landing — лендинг автосервиса «ТОРК»

Демо-лендинг СТО для показа заказчикам: `sto-landing/index.html`.
Один файл без сборки — просто откройте его в браузере или выложите на любой хостинг (GitHub Pages, Netlify и т.п.).

Блоки: hero с онлайн-трекером ремонта, услуги (bento-сетка, клик подставляет услугу в форму),
калькулятор стоимости, этапы работы, преимущества, отзывы, FAQ, онлайн-запись со слотами времени,
закреплённая панель «Позвонить / Записаться» на мобильных.

Название, телефон, адрес и цены — заглушки, замените на данные заказчика.
