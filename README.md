# cpace4games

## Лендинги автосервисов — портфолио

Три демо-лендинга СТО в разном оформлении. Каждый — один HTML-файл без сборки:
откройте в браузере или выложите на любой хостинг (GitHub Pages, Netlify и т.п.).

| Папка | Название | Стиль | Особенности |
|---|---|---|---|
| `sto-landing/` | ТОРК | Светлый bento, оранжевый + лайм | Онлайн-статус ремонта, калькулятор стоимости, запись со слотами времени |
| `sto-landing-2/` | ГАРАЖ 21 | Тёмный «техно», графит + неоновый голубой | Анимированный тахометр, счётчики, пакеты ТО, таймлайн с заполнением |
| `sto-landing-3/` | Мастерская «Колесо» | Светлый «семейный», зелёный + горчичный | Заголовок по словам, прайс во вкладках, карточки-стопка, слайдер отзывов |

Корневой `index.html` — страница-витрина со ссылками на все три сайта.

Все сайты адаптированы под телефоны и ПК, анимации отключаются при системной настройке
«уменьшить движение». Названия, телефоны, адреса, цены и отзывы — заглушки.
Список доработок для полной версии — в комментарии в начале каждого `index.html`.

### Публикация (GitHub Pages)

Settings → Pages → Source: **GitHub Actions**. Публикация запускается автоматически при каждом
пуше в `main` (workflow `.github/workflows/pages.yml`) или вручную во вкладке Actions.
Через 1–2 минуты сайты будут доступны:

- https://spacerunman.github.io/cpace4games/ — витрина
- https://spacerunman.github.io/cpace4games/sto-landing/
- https://spacerunman.github.io/cpace4games/sto-landing-2/
- https://spacerunman.github.io/cpace4games/sto-landing-3/
